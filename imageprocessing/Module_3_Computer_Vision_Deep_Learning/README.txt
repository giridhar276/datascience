MODULE 3: COMPUTER VISION USING DEEP LEARNING
================================================

This package contains 10 separate step-by-step Jupyter Notebooks and all
required local image datasets.

NOTEBOOKS
---------
01 Basic neural network for handwritten digits
02 CNN for handwritten digits
03 Binary CNN: animal vs transport
04 Multi-class CNN with real images
05 Data augmentation
06 Transfer learning with MobileNetV2
07 Fine-tuning MobileNetV2
08 Medical image-type CNN
09 Object detection with YOLO
10 U-Net image segmentation

INSTALLATION
------------
pip install -r requirements.txt

IMPORTANT
---------
- Open notebooks from the notebooks folder so relative dataset paths work.
- MobileNetV2 may download ImageNet weights on first use.
- YOLO may download its pretrained weights on first use.
- The medical example is educational and not a diagnostic system.
