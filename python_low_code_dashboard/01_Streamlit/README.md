# Streamlit Examples

Install dependencies from the root folder, then run any example:

```bash
streamlit run 01_executive_command_center.py
streamlit run 02_financial_scenario_lab.py
streamlit run 03_workforce_intelligence.py
streamlit run 04_technology_benchmark.py
streamlit run 05_risk_watchlist.py
```

The apps include filtering, calculated KPIs, interactive Plotly charts, tabs, scenario controls, session-state watchlists, and downloadable reports.
